# Backend - GameInventory

This is the **Express backend** for the GameInventory app.  
It handles all API requests, database operations, and middleware.

---

## 📂 Structure

backend/
├── app.js # Express app configuration
├── server.js # Entry point to start backend
├── routes/ # API endpoints
├── controllers/ # Route logic and business rules
├── model/ # Database queries and models
├── .env # Environment variables
└── package.json # Backend dependencies

---

## ⚡ Tech Stack

- Node.js
- Express.js
- PostgreSQL
- dotenv for environment variables
- pg for database connection
- CORS and Morgan for middleware/logging
